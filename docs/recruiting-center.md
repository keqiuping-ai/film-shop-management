# 招聘与面试中心

入口为电脑管理端的「功能模块 → 招聘与面试中心」。招聘档案与客户客资分开保存，招聘短信复用系统现有 Twilio 账号。新建预约默认线上视频面试；到店为备用方式，地址为 `3212 Santa Monica Blvd, Santa Monica, CA 90404`。所有面试时间按 `America/Los_Angeles` 展示和安排，存储使用带时区的时间。

## 操作流程

1. 新增应聘者，填写姓名、手机、邮箱、应聘职位和来源；补充履历、经销商关系、到岗时间、全兼职意愿等工作相关资料。
2. 打开档案先看到四步卡片：短信邀请、确认时间、线上面试、记录与评分。点击「短信邀请线上面试」只预填英文草稿，询问面试意愿和时间；必须生成英文预览并人工核对后才能发送。手机号、同意来源、退订和通道限制仍生效，不得虚填同意。
   - 发送确认已合并到「确认发送英文短信」按钮，不再要求额外勾选「我已核对」。预览本身不会发送短信；修改草稿后须重新生成预览，短信授权及退订检查不变。
3. 收到回复后，保存面试时间、方式和面试官。新预约默认为线上，线下地址不会进入线上邀请；保存预约本身不会通知应聘者。
4. 对方确认后，将预约标记为「已确认」。收到普通回复不会自动替对方确认时间。
5. 在预约控制台保存并生成一次性链接，点击「用英文短信发送链接」将链接带入草稿，核对后单独发送。生成新链接会使旧链接失效。面试官进入已有视频面试室；这几个操作互不代表短信已送达或候选人已加入。
6. 加入或到场后可人工标记「已加入 / 已到场」，完成后填写逐题评分或六项评分及事实依据。每项 1–10 分，未核实保持空白。未加入可询问连接问题或改期；修改时间或方式后需重新确认。录用等状态由招聘人员主动选择。

### 线上优先与旧预约兼容（2026-09-19）

- 预约 API 新增可选 `mode: "online" | "in_person"`。新界面明确提交 `online`；旧调用和历史缺失字段仍按 `in_person`，不自动转换旧到店预约、不批量重写资料。线上地址可空；到店地址仍必填。
- 详情页把主要动作放在资料上方，到店入口收进备用折叠区。紧凑资料卡、申请/录入时间区别、简历原件及中英对照保留。
- 在线确认、提醒和未加入模板使用视频面试措辞；旧到店预约仍使用到店措辞。自动提醒不会生成新链接，只提示使用单独收到的链接。实际视频、AI 和短信服务沿用已有配置，本轮不改密钥或环境。

简历支持文字、外部链接及最大 5MB 的 PDF 上传。上传文件保存在当前 `DATA_DIR/recruiting-resumes`，查看须登录并具有招聘查看权限。做完整备份时需要同时保留数据库和此目录；数据库 JSON 备份只含文件信息。

每次预约的自动短信提醒默认关闭。开启后，仅对候选人已确认的预约在面试前约 24 小时、2 小时各提醒一次，并检查短信授权及退订状态。服务恢复时不补发已经错过的旧提醒，也不在面试后自动发送迟到催促。手动邀约和迟到跟进可在对话中编辑后发送。测试/演示环境用 `RECRUITING_REMINDERS_ENABLED=false` 关闭后台自动发送；生产环境也可使用此开关统一关闭提醒。

六项评分为销售能力、经销商资源、首周开发计划、沟通表达、执行力和岗位匹配。两个业务方向是把经销商车辆引入门店施工，以及向有施工条件的商家销售汽车膜。评分应记录具体案例和可核实信息，不使用受保护特征，也不把口头承诺直接视为成交业绩。

## 权限及数据

- `recruitingView`：查看应聘者、面试、简历和沟通记录。
- `recruitingEdit`：维护档案、预约、评分和发送招聘短信；需要同时具备查看权限。
- 老板和经理默认具有上述权限，其他员工由老板在账号权限里单独授权。
- 招聘数据经独立 API 返回，不加入普通客户列表、客户销售统计或客户端数据。
- 招聘短信入站和送达回执按手机号、平台消息编号关联，重复回执不重复插入；短信入站不会启动客户促销或客户 AI 回复。
- 如号码同时出现在客户资料和招聘档案中，系统提示冲突并阻止不明确的发送。旧客户交流中的应聘记录不会被静默搬移或删除。
- 老板确认属于本人控制的测试号码后，可在该档案短信窗口开启 **24 小时测试**。例外绑定该档案 ID 与完整号码，记录批准人、原因、批准/到期时间，可随时关闭；换号自动失效。不会替代短信授权、退订、英文预览、号码核对或防重复发送保护。
- 测试只放行人工招聘短信，不开放共号的自动提醒或客户端发送。测试窗口内的新回复仅进对应招聘档案，不触发客户 AI/促销；测试前历史、到期或撤销后的共号回复继续隔离，旧客户记录及已有隔离记录不迁移、不删除。开启/关闭测试本身不发送短信。
- 邀请、提醒和失败状态只表示对应沟通步骤，不代表对方接受、到店或录用。
- 平台发送结果未知时会保留待核实记录，重复提交同一发送编号不会再次发送；收到平台送达回执后更新原记录。

## 本地验收

### 多面试官视频间（2026-09-19）

- 同一场预约使用同一视频房。面试官通过 `recruiting-interview.html?interview=...` 进入，须先登录具有招聘查看权限的系统账号；此链接不含登录凭据，也不是候选人的一次性邀请链接。增加面试官无需重新生成候选人链接。
- 每个面试官页面具有独立入会标识，即使同一账号在多个设备打开也不会使用相同视频身份；同一页面重连保留其身份。姓名和转写归属由服务器按登录账号确定，不接受客户端冒充候选人或其他面试官。
- 房间按参与者分别显示视频、姓名、角色与在线人数。摄像头关闭时保留该参与者占位；离开时移除其画面和音频。
- “离开面试”只断开自己的音视频，不结束其他人的会话；“结束所有人的面试”独立确认，且仍要求招聘编辑权限。仅有查看权限的面试官可以入会，但不能保存转写、请求分析或结束整个房间。
- 候选人仍通过原有一次性链接、说明确认及原浏览器会话重连。候选人接口不返回内部用户编号、招聘档案、简历笔记或 AI 评分。
- 不迁移候选人数据、不修改短信授权、不新增短信或邮件发送。多人 UI 使用本地模拟参与者验收；实际多设备音视频质量须在真实面试前测试。

### 短短信与发送原因提示（2026-09-18）

- 招聘短信没有最低字数要求：去除首尾空白后，1–1600 个字符均可提交；短消息不会补字或自动扩写成模板。1600 是上限，不是必须填满的目标。
- 字数提示明确显示英文预览的字符数及上限。发送按钮旁持续显示具体阻止原因，包含缺少/无效手机号、同意记录不完整、退订、通道未启用、未预览、未人工核对、收件人改变或正在处理。
- 前端核对美国手机号格式及短信同意来源，与后端既有保护保持一致。只有邮箱不能发送短信；应先补充真实手机号或改用已授权的邮件渠道，不能虚填号码或同意。
- 英文预览、人工确认、汉字拦截、号码冲突、退订及防重复发送保护不变。只运行虚拟数据和模拟服务测试，不向真实候选人发送测试信息。
- 验收：招聘测试全部通过（OpenAI 模拟 21、翻译/发送单元 138、日期 219、既有界面 14、短信界面 40、隔离 HTTP 182）。本地浏览器用虚拟候选人验证 `Hi` 核对后可提交到模拟服务；缺少手机号及同意记录时，`OK` 核对后仍显示具体拦截原因。
- 前端资源标记为 `recruiting.js?v=20260918-short-sms-1`。本次不修改后端、正式数据、服务配置或其他业务模块。

### 时间排序与大幅简历阅读（2026-09-17，已批准发布，线上验收待完成）

- `appliedAt` 是有来源依据的申请时间，支持仅日期 `YYYY-MM-DD` 或 UTC 时间；`applicationDateNote` 保存日期依据。缺失的历史申请时间保持未知，不从导入日期、面试日期或备注中的其他日期猜测。
- `createdAt` 为不可由客户端修改的录入系统时间。两种时间分别显示；仅有日期的记录不虚构具体时刻，精确时间按洛杉矶时区展示。
- 默认按已核实申请时间从近到远排序，未知申请日期置后并按录入时间排序；可切换为录入时间最近优先。跟进或修改资料不改变录入时间。
- 整行点击或键盘打开档案；短信和预约按钮仍保持独立操作。简历原文与译文扩大显示，可选择中文或英文对照目标，原文不会被翻译覆盖。
- 仅有 PDF 或外链而没有已保存简历文字时，仍可查看原件，但不声称已经提取或翻译全文。已保存文字也不等于原件完整性已核实。
- 本次发布不回填正式候选人日期、不发送真实消息。已核实的历史日期需要在正式版本发布后依来源补录。
- 开发版回归通过：21 项 OpenAI 适配器测试、117 项翻译与发送保护检查、219 项日期检查、14 项前端回归测试、182 项 HTTP 集成检查，以及原有客户订购安全回归。浏览器验证两种排序、点击非姓名单元格打开档案、修改跟进备注后申请时间保持不变，以及放大双栏显示完整测试文字；浏览器错误日志为空。译文使用本地预设模拟响应，未验证正式 AI 翻译质量。独立发布目录将再次执行回归。

### 中英档案与短信翻译（2026-09-17，已批准发布，线上验收待完成）

- 招聘翻译复用 `openAiCustomerReplyKey()` 和 `customerAiReplyModel()`：优先已有环境配置，否则读取系统已加密保存的 OpenAI 配置。不新增密钥，不向浏览器返回密钥，不带入客户对话或销售知识库。
- `POST /api/recruiting/translate` 接收 `{text,targetLanguage:"en"|"zh"}`，返回 `{text,targetLanguage}`。必须同时具有招聘查看与编辑权限；最多 60,000 字符，按用户限制调用次数、字符量和并发。
- 翻译仅用于按需审阅：保留原文，不自动更改候选人资料、同意状态或面试时间，不自动发送。AI 返回不完整内容、数字或联系方式不一致时拒绝采用译文。校验不能代替人工核对。
- 招聘短信前后端均禁止 Unicode 汉字（含扩展区）。自动提醒如果包含中文姓名或地址，也不会发送。仍须记录有效短信同意、未退订且无客户号码冲突；中文拦截不是所有非英语语言的自动识别器。
- 单元与 HTTP 测试只用虚拟文本、临时数据库、回环 AI/Twilio 模拟服务；不使用正式密钥或真实候选人。模拟测试不证明正式 OpenAI 配额、模型权限或 Twilio 送达能力，发布后需独立验证。
- 本轮没有接入招聘邮箱收件同步；邮件按钮仍打开外部邮件客户端，不代表邮件已发送。
