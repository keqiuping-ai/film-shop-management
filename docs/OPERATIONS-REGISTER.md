# 运营事务台账

在功能模块中打开“运营事务台账”。

1. 新建公司／地点档案。档案名称与法定名称独立；法定名称不知道时留空，填写当前情况和待解决问题。
2. 添加会计、财务、保险、物业等联系人，记录机构、联系方式和负责范围。
3. 在档案卡片点击“添加待核实检查清单”，加入11项常见运营检查项。重复点击不会重复添加。所有项目初始均为待核实，无预设法定截止日期。
4. 编辑每项事务，勾选一个或多个负责人、关联联系人，填写办理截止日、复查日期及周期。
5. 在“详情／复查”中填写本次复查结果、状态和凭证位置。系统保留历史并推进复查日期；办理截止日独立保留。

老板维护全部档案和任务。员工仅能读取自己被分配的任务及相关公司与联系人，并提交复查；不能修改分配和公司档案。无需把员工设为老板。

总表显示未完成、办理逾期、到期复查及未分配数量，可按公司、状态、关键字、本人负责和逾期／复查过滤。归档记录默认隐藏，可选择归档状态查看。

提醒当前在台账内显示，没有发送邮件、短信或后台推送。凭证以文字位置说明保存，本模块不上传文件、不自动支付、不自动判定法律适用性。

数据保存在现有 db.json 的 operations 集合，沿用备份。旧数据库不需要预先迁移。读写使用现有身份认证和原子写入；编辑和复查使用版本号拒绝过期更新。

验证：`npm run test:operations`。浏览器与HTTP验收应使用隔离 DATA_DIR，不能对生产数据执行演示脚本。
