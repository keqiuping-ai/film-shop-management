# 运营事务台账

在功能模块中打开“运营事务台账”。

1. 新建公司／地点档案。档案名称与法定名称独立；法定名称不知道时留空，填写当前情况和待解决问题。
2. 添加会计、财务、保险、物业等联系人，记录机构、联系方式和负责范围。
3. 在档案卡片点击“添加待核实检查清单”，加入19项常见运营检查项。重复点击不会重复添加。所有项目初始均为待核实，无预设法定截止日期。
4. 编辑每项事务，勾选一个或多个负责人、关联联系人，填写办理截止日、复查日期及周期。
5. 在“详情／复查”中填写本次复查结果、状态和凭证位置。系统保留历史并推进复查日期；办理截止日独立保留。

老板维护全部档案和任务。员工仅能读取自己被分配的任务及相关公司与联系人，并提交复查、上传文件和添加留言；不能修改分配和公司档案。无需把员工设为老板。

总表显示未完成、办理逾期、到期复查及未分配数量，可按公司、状态、关键字、本人负责和逾期／复查过滤。归档记录默认隐藏，可选择归档状态查看。

每个事项分开保存事项说明、账单说明、文件资料和留言。文件可分类为证照、账单、付款凭证、保单、照片或其他，并记录日期、说明、上传人员和时间。总表显示文件和留言数量；搜索覆盖文件名、说明及留言。

支持PDF、JPG/JPEG、PNG、WebP，单份8MB，每项最多40份且总计64MB，台账总计256MB。上传保留旧文件，不能通过普通事项编辑覆盖文件及留言。上传和留言带提交编号，重试不重复添加。留言保留人员与时间，复查历史独立保留。

文件只通过登录后的授权接口读取，没有公开文件链接；取消负责人分配后，该员工无法再下载对应文件。列表只返回文件元数据，内容保存在数据库中，随现有数据库备份保留。容量上限用于控制现有JSON数据库的体积；扩大资料库前应迁移到私有对象存储，并同步设计完整备份与恢复。

每期账单独立记录项目、服务商、币种和金额、账期、本期应付日期、付款状态、实际付款人、实际付款日期、方式、交易参考号、已缴费覆盖至、下一期完整缴费日期，并可关联本事项附件。实际付款人与跟踪负责人分开。可更新付款信息，保留原内容及修改人；新账期新增记录，不覆盖上期。重复提交不会新增重复记录，过期编辑会被拒绝。

清单统一使用“互联网／宽带缴费”，涵盖普通宽带和Starlink（星链），通过服务商区分。旧版重复项会自动合并并保留文件、账单、留言、历史、负责人和联系人；原日期及状态保存在合并记录内。总表显示每项缴费期数、下一期日期及尚未付款的最早到期日，未付款账单和下期续费逾期也计入逾期统计。已付款状态由人员记录，系统不连接银行核验。

检查清单新增车辆上牌／注册／续牌、车辆保险、车辆年检／排放检测适用性，均可指定内部负责人和外部代办／经纪联系人。具体适用要求和日期需要核实。

提醒当前在台账内显示，没有发送邮件、短信或后台推送。本模块不自动支付、不自动判定法律适用性。

数据保存在现有 db.json 的 operations 集合，沿用备份。旧数据库不需要预先迁移。读写使用现有身份认证和原子写入；编辑和复查使用版本号拒绝过期更新。

验证：`npm run test:operations`。浏览器与HTTP验收应使用隔离 DATA_DIR，不能对生产数据执行演示脚本。


## 公司账号、邮箱与离职交接

“账号与邮箱”入口管理广告账号和公司邮箱。新建账号类档案，可填写平台／服务商、账号标识／公司邮箱地址、注册邮箱、HTTPS登录主页、所属部门，以及申请联系人、邮箱、电话和申请流程。文字、照片、PDF、账单与留言沿用单项资料保存方式。

老板可明确启用“向员工显示申请入口”。此时所有员工只能看到平台、部门、申请联系人和流程；完整账号标识、注册邮箱、文件、账单和留言仍仅向老板及指定负责人开放。这样新业务员能找到邮箱申请人，无需获得账号档案的完整权限。

“离职／客户交接”入口可新建普通人员或业务员交接单，记录部门、交出人、原系统账号、接收员工、最后工作日和交接范围。指定的接收员工自动加入该交接单的跟踪负责人；交出人不会自动获得访问权。账号档案可关联到交接单，但关联本身不增加账号档案查看权限。

交接清单支持客户、账号／邮箱、资料、设备、访问权限和其他项目，每项记录联系方式、当前情况、未完成事项和下一步。状态区分待交接、已交出待接收、接收人已确认及不适用。接收确认由指定接收员工本人提交，并保留修改前内容、人员和时间；其他人不能更改已确认项目。

业务员交接单中，老板可按原员工系统账号导入当前分配给他的 salesAccounts 外勤客户，保留客户联系方式、阶段和跟进摘要及下一步的快照；重复导入不重复新增。其他来源的客户可手工补录。报价、订单、回款、售后是否未完成需要逐客户核实；本版本不自动重分配客户、不更改员工状态、不创建邮箱，也不更改外部账号权限。


## 服务联系人与车辆汇总

联系人可按快递员、快递公司、搬运、电工、水管工、贴膜技师、货车运输、会计、保险、物业、推广和邮箱管理员分类，填写服务地区、预约方式和服务说明。通讯录支持分类筛选和关键字搜索，已填写有效电话／邮箱时显示拨号／写邮件入口，由用户自行发起联系。

老板可以选择向员工公开服务联系人。公开目录只显示姓名、机构、电话、邮箱、服务地区、联系时间和服务说明；内部备注和公司档案内容不会因此公开。未公开的联系人沿用指定事项权限。

总表按公司将车辆事项折叠为一栏“车辆管理”，汇总待办理数量、逾期和复查提示。点击进入后分别查看上牌、保险、年检等独立事项；原负责人、联系人、日期、文件、账单和历史均保留，没有合并数据库记录。搜索和状态筛选仍生效。
